The basics

What this site is

This is a class project inspired by the San Diego Rescue Mission, a nonprofit that serves people experiencing homelessness in San Diego. We are not affiliated with the organization, and nothing here is official. All names, rates, shifts, addresses, and hours are placeholders stored in JSON files and marked “TODO: verify”.

Who built it

Built by students in a computer science course as part of the Open Coding Society curriculum. Team member names are left out on purpose; add your team's first names or GitHub usernames here if your class requires it.

How it works

✓Plain HTML, SASS, and vanilla JavaScript on a Jekyll site, with no frameworks or build tools.

✓Styling comes from the shared OCS SASS system, using its ocs__ component classes and theme color tokens.

✓Each tool reads a JSON file in assets/data/sdrm/, so updating information never requires editing code.

✓Pages are built to work with a keyboard, a screen reader, and a phone screen 375 pixels wide.

Privacy

This site does not take payments or ask for personal information. The volunteer demo remembers which shifts you clicked only in your own browser's storage, and the “Reset demo spots” button clears it.
